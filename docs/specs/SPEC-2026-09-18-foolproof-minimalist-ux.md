# SPEC-2026-09-18: Foolproof Minimalist UX & Auto-Folding Viewport Density
**Статус:** APPROVED | **Уровень риска:** Tier 2 (Standard SDD) | **Версия:** 1.0.0

---

## 1. Проблема и Бизнес-Контекст
1. **Перегрузка экрана (Vertical Height Bloat):** При создании интерактивных визардов и форм заказов разработчики и дизайнеры часто раскрывают все шаги подряд (ссылка $\to$ категории $\to$ услуги $\to$ степпер $\to$ оплата), превращая экран в бесконечную простыню ($> 400\text{px}$), которая вытесняет активные заказы, аналитику и баланс за пределы первого экрана (Below-the-fold).
2. **Когнитивный перегруз новичков (Analysis Paralysis):** Сложные технические интерфейсы с десятками фильтров, чекбоксов и жаргоном («Drip-Feed», «Интервал», «Drop-down ID», «TargetType») отпугивают обычных пользователей («дураков» / клиентов без IT-опыта).
3. **Цель скилла:** Обязать любого AI-ассистента (Antigravity, Cursor, Claude Code) следовать жестким принципам:
   - **Auto-Folding (Авто-схлопывание):** При выборе следующего шага предыдущие громоздкие селекторы автоматически схлопываются в 1-строчный бейдж с возможностью отката в 1 клик.
   - **Foolproof Design (Интерфейс «для дураков»):** В каждый момент времени доступно ровно ОДНО главное действие. Никакого жаргона — только простые действия («Вставить ссылку», «Выбрать категорию», «Оплатить»).

---

## 2. Архитектурные Инварианты (Hard Invariants)

1. **Auto-Folding Invariant (Правило схлопывания пройденных шагов):**
   При переходе на шаг $N+1$ сетка или список шага $N$ обязана скрываться, уступая место 1-строчной хлебной крошке/плашке высоты $\le 36\text{px}$ вида `[✓ Шаг N: Выбранное значение] [Сменить]`.
2. **Single Active Action Rule (Одно активное действие на экран):**
   Пользователь не должен видеть форму чекаута, пока не выбрал услугу; не должен видеть услуги, пока не выбрал категорию; не должен видеть категории, пока не ввел валидную ссылку.
3. **Viewport Budget Invariant (Лимит высоты виджета):**
   - В состоянии покоя: высота $\le 60\text{px}$.
   - В максимально раскрытом состоянии с чекаутом: высота $\le 220\text{px}$.
   - Запрещено вытеснять таблицу заказов или баланс за первый экран.
4. **Forgiving Rollback Invariant (Откат в 1 клик без потери контекста):**
   Пользователь в любой момент может нажать «Сменить категорию» или «Сбросить» и мгновенно вернуться на предыдущий шаг без перезагрузки страницы.
5. **No Jargon / Plain Language Standard:**
   Запрещено использовать технический сленг провайдеров в UI для клиентов. Вместо «Drip-feed chunks» — «Постепенный запуск», вместо «API provider service ID» — понятное название тарифа с гарантией.

## 3. Модель Данных и Контракт Состояний (FSM)

```typescript
export type WizardPhase = 
  | 'INPUT_LINK'          // Состояние 0: только поле ввода ссылки (<= 56px)
  | 'CATEGORIES_OPEN'     // Состояние 1: сетка категорий открыта
  | 'CATEGORY_COLLAPSED'  // Состояние 2: категория свернута в бейдж + открыты тарифы
  | 'ORDER_CONFIRMED';    // Состояние 3: заказ оформлен, возврат в исходное

export interface CollapsedStepSummary {
  stepIndex: number;
  label: string;
  value: string;
  icon?: string;
  canEdit: boolean;
}
```
