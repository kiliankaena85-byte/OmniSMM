# SPEC-2026-09-13: Next-Gen Agent Skills Architecture v2 (CDD-TDD)

## 1. Контекст и Проблема
Текущая нормативная база из 56 скиллов платформы OmniSMM 1.0 хранится в виде объемных Markdown-файлов (`SKILL.md`, 250–450 строк каждый). 
При одновременной активации 3–4 скиллов (например, при правке биллинга с 54-ФЗ и мульти-тенантностью) расходуется до 15 000 токенов контекста, вытесняя целевой код и повышая стоимость и задержку ответов модели.
Кроме того, отсутствует механизм динамической маршрутизации интентов пользователя на скиллы и механизм систематического обучения скиллов на базе устраненных багов.

## 2. Архитектурные Требования
1. **Двухуровневая модель L1 / L2:**
   - Каждая папка скилла содержит:
     * `CORE.md` (L1 Core Invariants): компактный файл строго до 65 строк, содержащий детерминированные инварианты, ключевые формулы и запреты.
     * `SKILL.md` (L2 Deep Spec): существующая полная спецификация с деревьями решений, премортемами и примерами.
2. **JIT Skill Router CLI (`scripts/skill-router.ts`):**
   - Анализирует пользовательский запрос или описание задачи.
   - Определяет топ-N релевантных скиллов (confidence $\ge 0.65$).
   - Выводит готовый ультра-компактный системный промпт из содержимого файлов `CORE.md` (бюджет $\le 1500$ токенов вместо 15 000).
3. **Skill Evolving Hook (`scripts/skill-evolve.ts`):**
   - Позволяет агенту после закрытия инцидента добавить извлеченный урок в секцию `## Known Anti-Patterns & Lessons Learned` скилла.
   - Валидирует входные параметры по схеме `SkillEvolutionLessonSchema`.
   - Гарантирует атомарность операции и сохранение резервной копии.
4. **Test Suite:**
   - 100% покрытие тестами в `src/__tests__/skills/skills-architecture-v2.test.ts`.
