# Спецификация: Устранение ложного срабатывания массового заказа (Mass Mode) при вводе ссылки или Email (SIL-2026 / OED-2026)

## 1. Контекст проблемы и дефекта

### Описание инцидента
Пользователь сообщил о критическом дефекте пользовательского опыта (UX):
1. При вводе email-адреса (`Guzal_ya_1987@gmail.com`) в поле ввода ссылки открывается интерфейс массового заказа (`UniversalOrderForm` / "Настроено 1 из 50", со строками вида `4. Guzal_ya_1987@gmail.com ОЖИДАЕТ НАСТРОЙКИ (OTHER)`).
2. При вставке ссылки на канал/пост, скопированной из мессенджера или браузера (содержащей завершающий перенос строки `\n` или случайный пробел), витрина сайта мгновенно демонтирует 4-шаговый визард и каталог тарифов, заменяя их на интерфейс массового заказа ("Режим Умной Корзины активирован!").
3. Пользователи оказываются дезориентированы, не могут выбрать тариф или завершить оформление стандартного одиночного заказа.

### Корневые причины (Root Cause Analysis)
1. **`src/hooks/useOrderEngine.ts` (строка 288):**
   ```typescript
   const isMassMode = url.includes("\n") || url.split(/\s+/).filter(Boolean).length > 1;
   ```
   Условие `url.split(/\s+/).filter(Boolean).length > 1` или `url.includes("\n")` ложно срабатывало на:
   - Любую ссылку со случайным пробелом или символом новой строки на конце.
   - Любой email-адрес с пробелом.
   - Любой текст с пробелами, вставленный пользователем.

2. **`src/components/landing/LandingCatalogContent.tsx` (строка 96):**
   ```typescript
   if (showSmartCart || engine.isMassMode) {
     return <UniversalOrderForm ... />;
   }
   ```
   При переходе `engine.isMassMode` в `true` компонент витрины полностью скрывал `MobileWizard`, `NetworkSelector`, `CategorySidebar` и `ServiceGrid`, подменяя их на `UniversalOrderForm`.

3. **`src/components/landing/order-engine/HeroInput.tsx` (строки 105, 262–269):**
   - На событие `onPaste`:
     ```typescript
     if (pastedText.includes('\n') || pastedText.split(/\s+/).filter(Boolean).length > 1) {
       e.preventDefault();
       setUrl(pastedText);
       if (linkHasError) setLinkHasError(false);
       toast.success("Режим Умной Корзины активирован!");
       return;
     }
     ```
     Любая вставка с пробелом или новой строкой блокировала штатную очистку UTM-меток, вызов нормализации ссылки и выбрасывала тост "Режим Умной Корзины активирован!".
   - В разметке: при `isMassMode === true` скрывался 3-шаговый навигатор и поле одиночной ссылки, а вместо них рендерилась `textarea` с плейсхолдером `ID услуги | Ссылка | Количество`.

4. **`src/utils/link-extractor.ts` (строка 17):**
   ```typescript
   results.push(token); // Fallback: keep the raw string
   ```
   В `UniversalOrderForm` функция `extractLinks` помещала любые строковые токены (включая email-адрес `Guzal_ya_1987@gmail.com`) в качестве ссылок с категорией `OTHER`, создавая фантомные заказы.

## 2. Архитектурные требования и инварианты

1. **Инвариант одиночного заказа (Single-Order Priority Invariant):**
   - Главная витрина сайта (`/`) по умолчанию предназначена для одиночных заказов (Ссылка $\to$ Тариф $\to$ Оплата).
   - Никакой ввод или вставка единичной ссылки (даже с пробелами, переносами строк, протоколами или без них) НЕ ДОЛЖНЫ переключать интерфейс витрины в режим массового заказа.

2. **Канонический детектор массового заказа (`isStructuredMassOrderText`):**
   - Текст квалифицируется как массовый заказ СТРОГО при соблюдении формата панелей:
     `ID_Услуги | Ссылка | Количество`
   - Требования к синтаксису:
     - Минимум 2 непустые строки (пакетный заказ) ИЛИ явный синтаксис `\d+\s*\|\s*https?:\/\/[^\s|]+\s*\|\s*\d+`.
     - Наличие разделителей `|`.
     - Первый токен — целое положительное число (ID услуги).
     - Третий токен — целое положительное число (Количество).
   - Случайный текст, email-адреса, одиночные ссылки с пробелами НЕ МОГУТ быть классифицированы как массовый заказ.

3. **Изоляция витрины (`LandingCatalogContent`):**
   - Каталог услуг на лендинге НЕ ДОЛЖЕН скрываться при случайном вводе текста. `UniversalOrderForm` монтируется строго при явном включении `showSmartCart` через специализированный переключатель/кнопку, а не от изменения содержимого `engine.url`.

4. **Интеллектуальная обработка `onPaste` в `HeroInput`:**
   - Если вставлен email (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`): очистить от пробелов, активировать баннер быстрого сохранения email, не трогать массовый заказ.
   - Если вставлен структурированный массовый заказ: активировать массовый заказ.
   - Во всех остальных случаях: очистить от переносов строк, извлечь целевую ссылку, очистить от трекинг-параметров (`stripQueryParams`), нормализовать юзернейм (`normalizeUsername`) и передать в одиночный движок заказов.

5. **Гигиена `extractLinks` (`link-extractor.ts`):**
   - Не добавлять в список ссылок токены, являющиеся email-адресами (`isEmail`).

## 3. Матрица верификации (TDD Scenarios)

1. **Сценарий 1: Вставка email-адреса**
   - Вход: `Guzal_ya_1987@gmail.com\n`
   - Ожидание: `isMassMode === false`, email распознан, витрина и каталог тарифов остаются на экране.
2. **Сценарий 2: Вставка ссылки с завершающим переносом строки или пробелами**
   - Вход: `  https://t.me/smmMarket69 \n  `
   - Ожидание: `isMassMode === false`, `url === "https://t.me/smmMarket69"`, витрина и каталог тарифов активны.
3. **Сценарий 3: Вставка текста с несколькими словами**
   - Вход: `https://t.me/durov мой любимый канал`
   - Ожидание: `isMassMode === false`, извлекается каноническая ссылка `https://t.me/durov`.
4. **Сценарий 4: Настоящий структурированный массовый заказ**
   - Вход:
     ```
     15 | https://t.me/durov | 100
     18 | https://vk.com/wall-1_1 | 500
     ```
   - Ожидание: `isMassMode === true`, успешно передается на расчет в `massOrderCalculateAction`.
