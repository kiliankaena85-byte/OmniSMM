# UI Theme Architect — Архитектурный Стандарт Дизайн-Системы и Тем OmniSMM (2026)

## 1. Назначение и Зона Ответственности
Скилл регламентирует полный жизненный цикл тем оформления, дизайн-токенов, рефакторинга компонентов и контроля доступности:
1. Создание новых тем: алгоритмический синтез гармоничных пар Light/Dark на базе Google HCT / OKLCH из Seed Color.
2. Рефакторинг существующих компонентов: очистка от хардкода (`text-white`, `bg-black`, `#hex`), переход на семантические токены.
3. Проверка контрастности: математический аудит по стандартам WCAG 2.2 AA ($\ge 4.5:1$ для текста, $\ge 3.0:1$ для бейджей) и APCA.
4. Мульти-тенантная изоляция: разделение стилей SMMplan (`smmplan.pro`) и SMMflux (`smmflux.ru`) без конфликтов в DOM.

---

## 2. Ключевые Архитектурные Инварианты
- **CSS-First Tailwind 4:** Базовые токены определяются в блоке `@theme` в `src/app/globals.css`.
- **Селекторы тем:** Темы переключаются через классы или атрибуты `[data-theme="<name>"]` и класс `.dark`.
- **HeroUI v3 Интеграция:** Семантические токены HeroUI (`--color-content1`, `--color-content2`, `--color-content3`) синхронизированы с переменными темы.
- **Zero-Slop Standard:** Запрет 5 ИИ-клише: *Purple on dark*, *Icon-stuffed bento*, *Biscuit pills*, *Blob meshes*, *Gradient keyword fatigue*.

## 4. Контроль Качества и CLI-Харнес
Инженер или ИИ-агент обязан выполнять верификацию через встроенный харнес:
- `npm run theme:audit` — сканирование кодовой базы на предмет нелегального хардкода цветов;
- `npm run theme:contrast` — проверка математического контраста всех зарегистрированных тем;
- `npm run theme:generate -- --seed="#0369a1" --name="sky-pro"` — генерация новой темы.
