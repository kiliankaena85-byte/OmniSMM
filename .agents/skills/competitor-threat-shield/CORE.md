# competitor-threat-shield (L1 Core Invariants)
> **Статус:** ARCHITECTURAL GATE | **Бюджет:** < 400 токенов | **Слой:** L1 Fast Core

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **Инвариант 1:** Zero Provider Exposure: имена и ID внешних поставщиков никогда не передаются клиенту.
2. **Инвариант 2:** Catalog Rate Limiting: эндпоинты каталога защищаются скользящим окном лимитов запросов (RFC 9331).
3. **Инвариант 3:** Canary Token Defense: база данных снабжена контрольными записями для фиксации кражи в суде.
4. **Инвариант 4:** Dynamic Price Obfuscation: защита от автоматизированного мониторинга цен конкурентами.
5. **Инвариант 5:** Search Bot Whitelist: официальные поисковые роботы Яндекса и Google не блокируются защитой.

## ⚡ FAST RULES & FORMULAS
- Основное правило: строгое следование стандартам платформы OmniSMM 1.0.
- Автоматическая проверка: `npm run lint:skills -- --skill=competitor-threat-shield`.
