# self-healing-ooda-loop (L1 Core Invariants)

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **Инвариант 1:** Bounded Retry Limit: не более 3 автоматических итераций исправления на одну ошибку.
2. **Инвариант 2:** Immediate Rollback: при появлении новых регрессий система откатывается к стабильному состоянию.
3. **Инвариант 3:** Mandatory Regression Test: каждое исправление сопровождается тестом, воспроизводящим сбой.
4. **Инвариант 4:** Audit Logging: все шаги петли самоисцеления фиксируются в неизменяемом журнале аудита.
5. **Инвариант 5:** Fail-Safe Default: при невозможности автоматического лечения система переходит в защищенный режим.
