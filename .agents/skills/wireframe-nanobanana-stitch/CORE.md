# wireframe-nanobanana-stitch (L1 Core Invariants)
> **Статус:** CRITICAL GATE | **Бюджет:** < 450 токенов | **Слой:** L1 Fast Core

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **Pipeline Discipline:** ЗАПРЕЩЕНО пропускать этапы: строго соблюдать цепочку `Идея -> Wireframe -> Nano Banana -> Google Stitch -> React 19`.
2. **Monochrome Wireframe Law:** ЗАПРЕЩЕНО добавлять яркие цвета, финальные градиенты и тени на этапе Wireframe. Только серые тона, `border-dashed` и плейсхолдеры.
3. **Geometry Lock Invariant:** В промпте к Nano Banana ОБЯЗАТЕЛЬНО фиксировать геометрию скриншота вайрфрейма через `[INPUT ANCHOR]`. Запрещено менять структуру и положение элементов.
4. **Zero-Slop Standard:** В Google Stitch строго блокировать 5 ИИ-клише: фиолетовый неон на черном, эмодзи в бенто, пульсирующие пилюли над H1, blob mesh и градиентный текст.
5. **Production Purity:** Сгенерированный код обязан использовать React 19, Tailwind 4 (`@theme`), Touch Targets >= 44px и соблюдать Zero Horizontal Scroll.

## ⚡ FAST RULES & TRANSITIONS
- Wireframe: `bg-gray-50 text-gray-800 border-dashed border-gray-300 rounded`.
- Nano Banana: `[INPUT ANCHOR]: <FIRST_FRAME> + Design DNA (Swiss Kinetic / Financial / Obsidian)`.
- Stitch: Декомпозиция на независимые компоненты (< 200 строк) + Server Actions.
