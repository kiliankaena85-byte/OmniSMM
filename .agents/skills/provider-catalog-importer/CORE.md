# provider-catalog-importer (L1 Core Invariants)
> **Статус:** ARCHITECTURAL GATE | **Бюджет:** < 400 токенов | **Слой:** L1 Fast Core

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **Инвариант 1:** Admin Priority #1: ручной выбор категории администратором исполняется безусловно.
2. **Инвариант 2:** Zero-Unknown-Platform: услуги с неопределенной соцсетью (platform: other) запрещено импортировать.
3. **Инвариант 3:** No False-Branding: префикс бренда соцсети добавляется только при 100% подтверждении провайдером.
4. **Инвариант 4:** Service #ID Badge: каждая карточка услуги обязана содержать кликабельный бейдж #ID с копированием.
5. **Инвариант 5:** Price Margin Guard: розничная цена услуги обязана превышать себестоимость провайдера.

## ⚡ FAST RULES & FORMULAS
- Основное правило: строгое следование стандартам платформы OmniSMM 1.0.
- Автоматическая проверка: `npm run lint:skills -- --skill=provider-catalog-importer`.
