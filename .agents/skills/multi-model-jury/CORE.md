# multi-model-jury (L1 Core Invariants)
> **Статус:** ARCHITECTURAL GATE | **Бюджет:** < 400 токенов | **Слой:** L1 Fast Core

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **Инвариант 1:** Minimum 3 Independent Models: консилиум обязан опрашивать не менее 3 независимых моделей.
2. **Инвариант 2:** Blind Evaluation: первичное мнение формируется изолированно без перекрестного влияния.
3. **Инвариант 3:** Consensus Floor >= 80%: критическое решение принимается только при согласии от 80% моделей.
4. **Инвариант 4:** Mandatory Red Teaming: минимум один участник консилиума обязан атаковать решение в роли оппонента.
5. **Инвариант 5:** ADR Record Invariant: аргументы и итоговый вердикт консилиума обязательно фиксируются в ADR.

## ⚡ FAST RULES & FORMULAS
