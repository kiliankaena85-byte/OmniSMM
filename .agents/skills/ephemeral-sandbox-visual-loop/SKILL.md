# Ephemeral Sandbox & Visual Verification Loop (BGS-2026 Protocol)

> **Стандарт платформы OmniSMM 1.0 (2026)**  
> **Фундаментальный закон:** Консольные юнит-тесты слепы к визуальным артефактам, наложениям z-index, обрезке колонок, паразитному скроллу и сбоям гидратации React 19. Любое изменение перед попаданием в прод ОБЯЗАНО разворачиваться в изолированном Stage-контуре (:3005) и проходить сквозной аудит в headless-браузере под ключевыми ролями пользователей.

---

## 1. Архитектурная Изоляция (Blue-Green Stage)

### 1.1. Разделение Контуров (Port Isolation)
- **Production (Боевой контур):** Работает на порту `3000` (`http://127.0.0.1:3000`), обслуживает живой трафик через Tailscale Funnel. Категорически запрещено пересобирать или перезапускать in-place.
- **Stage / Ephemeral Sandbox:** Запускается на изолированном порту `3005` (`http://127.0.0.1:3005`). Не пересекается с продакшн-процессом Next.js.
- **Идемпотентная БД:** Использует общую или ветвящуюся схему PostgreSQL с изолированными сессиями (`sessionVer`, `contour: 'test'`).

## 3. Жесткие Инварианты и Антипаттерны (Hard Invariants & Anti-Patterns)

1. **ТАБУ №1: In-Place Production Rebuild:**
   - ❌ **ЗАПРЕЩЕНО** выполнять `docker-compose up -d --build web` или `npm run build` прямо на работающем продакшне без предварительной верификации на порту 3005.
2. **ТАБУ №2: Blind Deployment (Деплой вслепую):**
   - ❌ **ЗАПРЕЩЕНО** рапортовать об успешном изменении UI без сохранения графических доказательств (PNG-скриншотов) в директории `.planning/stage_visuals/`.
3. **ТАБУ №3: Horizontal Scroll Violation:**
   - ❌ **ЗАПРЕЩЕНО** появление горизонтальной полосы прокрутки на экранах шириной $\ge 360\text{px}$. Правило `document.documentElement.scrollWidth <= window.innerWidth` является блокирующим ассертом.
4. **ТАБУ №4: Hydration Warning Suppression:**
   - ❌ **ЗАПРЕЩЕНО** игнорировать или глушить предупреждения Next.js `Text content did not match` или `Hydration failed`. Любая ошибка в консоли браузера переводит статус аудита в `FAIL`.

## 4. Премортем-Анализ и Моделирование Отказов (Failure Scenarios)

| Сценарий отказа | Вероятность x Влияние | Защитный механизм в BGS-2026 |
| :--- | :--- | :--- |
| **Порт 3005 занят зависшим процессом Node.js** | Средняя x Высокая | Скрипт проверяет сокет через `net.Socket()`. При невозможности биндинга выводит PID и корректно освобождает ресурс либо использует резервный свободный порт. |
| **Падение браузера Chromium из-за нехватки RAM в контейнере** | Низкая x Критическая | Playwright запускается с флагами `--no-sandbox`, `--disable-dev-shm-usage`, `--disable-gpu` для гарантированной стабильности в headless-окружении. |
| **Тестовый пользователь отсутствует в БД при генерации JWT** | Низкая x Высокая | Аудитор автоматически подбирает первого подходящего пользователя по роли (`findFirst({ where: { role } })`) либо создает эфемерную тестовую сессию с `sessionVer: 1`. |
