# foolproof-minimalist-ux (L1 Core Invariants)
> **Статус:** CRITICAL GATE | **Бюджет:** < 450 токенов | **Слой:** L1 Fast Core

## 🛑 HARD INVARIANTS (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО)
1. **No Infinite Vertical Accordions:** ЗАПРЕЩЕНО раскрывать шаги формы стопкой без авто-схлопывания предыдущих. При выборе категории сетка категорий ОБЯЗАНА свернуться в 1-строчный бейдж.
2. **Single Active Focus:** ЗАПРЕЩЕНО показывать пользователю более ОДНОЙ точки принятия решения одновременно. Исключить когнитивный перегруз («интерфейс для дураков»).
3. **Height Budget Invariant:** Высота интерактивного виджета заказа в состоянии покоя $\le 60\text{px}$, в фазе выбора тарифа $\le 220\text{px}$. Запрещено вытеснять заказы из первого экрана.
4. **Forgiving Undo in 1 Click:** Любой свернутый шаг обязан содержать кнопку возврата (`[Сменить]`, `[Изменить]`). Пользователь никогда не должен перезагружать страницу для смены выбора.
5. **Zero Technical Jargon:** ЗАПРЕЩЕНО писать в клиенте слова «TargetType», «Drip chunks», «Provider ID», «API drop». Только кристально понятный русский язык («Канал», «Пост», «Гарантия»).

## ⚡ FAST RULES & TRANSITIONS
- `Ввод ссылки` $\to$ `Сетка категорий` $\to$ `Схлопывание в [✓ Категория · Сменить]` $\to$ `Тарифы и оплата`.
- Все тач-таргеты на мобильных устройствах строго $\ge 44\text{px}$.
- Цена ВСЕГДА за 1 шт («0.18 ₽ / шт»), итоговая сумма пересчитывается мгновенно.
