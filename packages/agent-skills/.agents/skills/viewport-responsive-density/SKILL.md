# Viewport Responsive Density & Zero-Scroll Guard

## 1. Назначение
Гарантирует 100% видимость информации без горизонтального скроллинга и обрезания колонок на ноутбуках и мобильных устройствах.

## 2. Стандарты компоновки
- Лимит колонок в таблице: 7–8 ключевых полей.
- Колонка ID: `w-16 font-mono text-[11px]`.
- Колонка действий: фиксированная ширина `w-20 text-right`.\n
