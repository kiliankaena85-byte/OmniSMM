# antigravity-flash-ui-refactor — Gemini Flash UI Refactoring Standard

## 1. Концепция: Особенности рефакторинга с Gemini Flash
Модель **Gemini Flash** обладает невероятной скоростью, но требует дисциплины вывода:
- При попытке переписать файл на 500+ строк модель может обрезать конец вывода или случайно опустить вспомогательный пропс.
- **Инженерный стандарт:** Любой сложный рефакторинг разбивается на атомарные шаги с использованием инструмента `replace_file_content` (Chunked Diff).

---

## 2. Протокол Chunked Diff (Пошаговый рефакторинг)
1. **Шаг 1: Анализ интерфейса (Interface Contract):**
   Фиксируются экспортируемые пропсы и типы:
   ```tsx
   export interface UserProfileCardProps {
     user: UserDto;
     onUpdate: (data: UpdateUserDto) => Promise<void>;
     className?: string;
   }
   ```
2. **Шаг 2: Выделение субкомпонентов:**
   Внутренние сложные секции (модалка подтверждения, аватарка со сменой фото) выносятся в отдельные файлы до 100 строк.
3. **Шаг 3: Точечная замена блоков через replace_file_content:**
   Замена старого JSX на компактный вызов субкомпонента без затрагивания остального кода файла.

---

## 3. Чеклист проверки чистоты рефакторинга
1. [ ] Файл укладывается в норматив $le 200$ строк.
2. [ ] Все пропсы и обработчики событий сохранены на 100%.
3. [ ] Код компилируется без единого ворнинга в `tsc --noEmit`.
4. [ ] Нет фантомных библиотек и депрекейтнутых хуков.
