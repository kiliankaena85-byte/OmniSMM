# Юридический и Финтех-Барьер (ст. 54.1 НК РФ, 54-ФЗ, 425-ФЗ)

> **Стандарт:** Налоговый кодекс РФ (ст. 54.1, 145, 164), 54-ФЗ (ФФД 1.2), 425-ФЗ (НДС 22%), 176-ФЗ (лимит УСН 20 млн ₽).  
> **Критический риск:** Обвинение ФНС в искусственном дроблении бизнеса при подключении партнерских сайтов.

---

## 1. Суть налогового риска ст. 54.1 НК РФ

Когда платформа масштабируется на несколько сайтов (SMMplan, SMMflux, витрина инвестора), налоговые органы РФ анализируют деятельность по следующим признакам «дробления бизнеса»:
1. Единый расчетный счет или единый эквайринг (общий Shop ID ЮKassa).
2. Общий IP-адрес/сервер без юридического разделения субъектов.
3. Единый персонал и управление без договоров коммерческой концессии/сублицензии.
4. Выручка распределяется искусственно для удержания планки 20 000 000 ₽ (освобождение от НДС по ст. 145 НК РФ).

**Последствия признания дробления:** Доначисление НДС 22% со всего совокупного оборота группы компаний + штраф 40% (ст. 122 НК РФ) + пени.

---

## 2. Архитектурный защитный барьер в OmniSMM 1.0

Для 100% защиты от претензий ФНС реализован принцип **Legal & Financial Sandboxing**:

### 1. Независимый эквайринг для каждого тенанта
У каждого партнера/инвестора свой договор с банком или ЮKassa:
```typescript
const context = await getTenantPaymentContext(tenantId);
// Использование строго изолированных ключей:
// context.yookassaShopId
// context.yookassaSecretKey
```
Категорически запрещено использовать один мерчант-аккаунт для разных доменов.

### 2. Раздельные онлайн-кассы по 54-ФЗ
Чеки формируются от лица юрлица/ИП конкретного тенанта:
- Уникальный регистрационный номер ККТ (`kktRegNumber`).
- Уникальный номер фискального накопителя (`fnNumber`).
- Правильный признак предмета расчета (`payment_subject`: `'payment'` для аванса, `'service'` для прямой оплаты услуги).

### 3. Автономный контроль лимита 20 млн ₽ (НДС 22%)
Функция `checkVatThreshold(tenantId)` рассчитывает чистую выручку индивидуально для каждого юрлица:
- До 20 млн ₽: `vat_code: 1` (Без НДС).
- Свыше 20 млн ₽: `vat_code: 10` (НДС 22% по 425-ФЗ).
- Смешение или перекрестный зачет выручки между тенантами заблокированы на уровне SQL CTE (`evaluateAndFlipVatThresholdAtomicCTE`).
